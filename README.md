# Лабораторная работа № 1. Социальная сеть

Консольная соцсеть, в которой можно добавлять, просматривать, изменять
и удалять пользователей, публикации и комментарии.

## Запуск

Нужен Python 3.10 или новее. Из папки проекта выполни:

```text
python main.py
```

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `main.py` | Классы, операции с записями, чтение и запись файлов, меню |

## Пример работы

1. Выбери `1`, затем `users` и введи имя. Первый пользователь получит ID 1.
2. Выбери `1`, затем `posts`. Введи ID автора и текст публикации.
3. Выбери `2` и `posts`, чтобы посмотреть публикации.
4. Для изменения или удаления выбери пункт `3` или `4`, тип записи и её ID.
5. Выбери `5` и введи имя файла, например `my-network.json` или
   `my-network.xml`. Чтобы открыть файл, выбери `6` и введи его путь.

При успешной загрузке файл заменяет текущие данные.

## Правила и ошибки

- Имя пользователя и текст записи обязательны.
- У публикации должен быть существующий автор. У комментария также должна быть
  существующая публикация.
- Удалить запись, на которую ещё ссылаются другие записи, нельзя.
- После ошибки можно выбрать новое действие в меню.
- Если файл повреждён или в нём есть неверная ссылка, загруженные ранее
  записи остаются в памяти.
